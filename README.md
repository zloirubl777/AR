# ПОЛИГОН 02.5 — модель распознавания без внешних CDN на телефоне

В архиве **нет тяжёлых бинарных файлов MediaPipe**. Их скачает GitHub Actions при публикации сайта, разместит рядом с index.html и опубликует в GitHub Pages. Это важно: просто заменить один index.html недостаточно!

## Как установить (GitHub AR)

1. В репозитории AR заменить корневой `index.html` из архива.
2. Добавить файл `.github/workflows/publish.yml` из архива, сохраняя путь с папками. На GitHub через браузер: Add file → Create new file → ввести имя `.github/workflows/publish.yml`, вставить содержимое и Commit changes. Если папки загружаются с компьютера, можно загрузить всё вместе.
3. В Settings → Pages → Build and deployment → Source выбрать **GitHub Actions** (вместо Deploy from a branch).
4. В Actions → «Publish POLIGON with local AI» запустить Run workflow, если действие не запустилось автоматически. Дождаться зелёного ✓ и опубликованной страницы.
5. Проверьте `https://zloirubl777.github.io/AR/vendor/ready.json` — должен отображаться JSON `engine: mediapipe-pose-0.10.21`.
6. На ОБОИХ смартфонах открыть `https://zloirubl777.github.io/AR/?v=25` → Дуэль → Человек без маркера → «Проверить локальный ИИ». После зелёного статуса «Модель загружена» подключить второе устройство.

**Если не менять источник GitHub Pages на GitHub Actions, локальные файлы не опубликуются.** Получите `AI-ASSETS-404`; старые режимы квадрата, зомби и MQTT-дуэль по квадрату останутся доступны.

## Что загружается

- npm: `@mediapipe/tasks-vision@0.10.21` (vision_bundle.mjs + нужные WebAssembly-файлы)
- Lite Pose Landmarker от Google: `pose_landmarker_lite.task`.

Все файлы модели скачиваются на этапе сборки в GitHub Actions. При открытии игры браузер получает их только с `zloirubl777.github.io`, не от CDN. Телефон по-прежнему должен быть в сети для сетевого режима MQTT.

## Диагностика

- `AI-ASSETS-404`: рабочий процесс GitHub Actions не выпущен или не выбрано развертывание GitHub Actions в Settings → Pages.
- `AI-ASSETS-NET`: сайт не отвечает на запрос проверки пакета.
- `AI-ASSETS-VERSION`: пакет не соответствует сборке.
- `MODULE/WASM/MODEL`: библиотека, WebAssembly или модель не смогли загрузиться; открыть Settings внутри дуэли и посмотреть подробности.

Расстояние без маркера пока не измеряется; несколько людей в кадре блокируют зачет. Не играть на проезжей части или рядом с лестницами.

Внешнюю доступность npm и модели из текущей среды проверить не удалось. Сборка GitHub Actions выполнит реальное скачивание на стороне GitHub; до её успешного завершения работоспособность локальной модели на телефоне не подтверждена.
