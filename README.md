# ПОЛИГОН 02.1 — диагностика комнат

В этой версии исправлен сценарий создания WebRTC-комнаты: 3 резервных CDN для PeerJS, видимый прогресс загрузки, подтверждение регистрации комнаты только после ответа PeerServer, тайм-ауты и понятные коды ошибок.

## Установка

1. Замените прежний `index.html` в корне GitHub-репозитория `AR`.
2. После публикации GitHub Pages откройте `https://zloirubl777.github.io/AR/?v=21`.
3. **На обоих телефонах должна стоять версия 02.1.** Коды комнат 02.0 и 02.1 несовместимы.
4. На первом смартфоне: `ДУЭЛЬ` → `СОЗДАТЬ КОМНАТУ`. Дождитесь зелёного сообщения «Комната ###### ГОТОВА!».
5. На втором смартфоне: `ДУЭЛЬ`, введите шестизначный код, затем нажмите `ПОДКЛЮЧИТЬСЯ ПО КОДУ`.
6. После сообщения «Оба телефона соединены» на обоих устройствах нажмите «В БОЙ».

Внимание: отображение цифр сразу после нажатия НЕ означает, что комната готова. Важно дождаться ответа от сервера.

## Диагностика

Кнопка «ПРОВЕРИТЬ СЕТЕВОЕ ПОДКЛЮЧЕНИЕ» показывает наличие WebRTC, PeerJS, состояние сети и доступность регистрации комнаты (если уже создана).

- `LIBRARY` — внешняя библиотека PeerJS не загружена; можно попробовать отключить блокировщик рекламы или сменить сеть.
- `HOST:network` / `HOST:server-error` — сервер PeerJS не отвечает/недоступен.
- `SIGNAL-TIMEOUT` — сервер не подтвердил комнату за 15 секунд. Код неактивен.
- `JOIN:peer-unavailable` — второй смартфон не нашёл зарегистрированную комнату. Убедитесь, что первый уже видит «Комната готова».
- `WEBRTC-TIMEOUT` — сервер познакомил телефоны, но прямой WebRTC-канал не открылся. Попробуйте единую Wi-Fi-сеть. Для некоторых сетей понадобится TURN-сервер.

Если проблема повторяется, сделайте скриншот окна дуэли с сообщением об ошибке и блоком «Этап / Тип».

## Технические ограничения

- GitHub Pages — только статический хостинг. Для комнат нужен публичный сигнальный сервис PeerJS (`0.peerjs.com:443`). Его бесперебойность не гарантируется.
- Для связи на сложных мобильных сетях может потребоваться отдельный TURN-сервер.
- Попадания пока рассчитываются на телефоне стрелка. Данная версия не является защищённой от читов.
- Два режима («Маркер» и «Зомби») сохранены без изменений. Режим «Зомби» пока не фиксирует объекты в пространстве при повороте камеры.
- Для полевого теста пока используется один чёрный квадрат, принтер не требуется.
