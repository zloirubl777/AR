# ПОЛИГОН 01.5 — «Маркер» + «Зомби — Выживание»

Один самостоятельный `index.html` для смартфонов. Тестовый проект, не коммерческая игра.

## Установка на GitHub Pages

1. В репозитории `AR` замените файл **`index.html`** новым `index.html` из архива.
2. Подтвердите сохранение (**Commit changes**).
3. Откройте `https://zloirubl777.github.io/AR/?v=15` после публикации. В заголовке должно быть **01.5**. GitHub Pages должен быть включён.
4. Разрешите камеру при запуске любого режима. HTTPS обязателен для доступа к камере.

## Режимы

**Маркер:** использует детектор версии 01.4. Нужен *один* имеющийся чёрный квадрат на светлом фоне. Можно включить виртуальный корпус и дальний поиск. Настройки и калибровка 01.4 сохраняются.

**Зомби:** маркер не нужен. Зомби анимированно накладываются поверх реального изображения камеры и приближаются. Выстрелы в голову уничтожают сразу, в корпус — после 3 попаданий. Доступны 5 волн, здоровье, боезапас, перезарядка (1,45 с), звук и 3 уровня сложности.

### Управление в режиме «Зомби»

- **ОГОНЬ** — выстрел по центру экрана; **ПЕРЕЗАРЯДКА** — замена магазина.
- Поворачивайте телефон влево/вправо, если доступен датчик ориентации; iOS может отдельно запрашивать разрешение.
- Также можно **вести пальцем горизонтально по изображению камеры**, чтобы менять виртуальное направление прицеливания. Это работает без гироскопа.
- **◎ ЦЕНТР** — сбросить относительное направление обзора.
- **НАСТРОЙКИ** — датчик ориентации, звук, сложность.
- **СТОП** — выход в выбор режима.
- **Демо зомби без камеры** — проверка механики в браузере на любом устройстве.

## Важные ограничения

Это *первая браузерная AR-композиция*, а не полное пространственное AR: программа пока **не строит карту комнаты**, **не распознаёт пол, стены, мебель и дверные проёмы** и **не вычисляет реальную дистанцию до зомби**. Расстояние и продвижение противников виртуальные; «фиксация» в направлении камеры приблизительна и зависит от гироскопа. Зомби могут визуально перекрывать реальные объекты неверно. Режим «Маркер» не требует распечатки дополнительных меток. Сетевой режим пока не реализован.

Игра не отправляет изображение с камеры на сервер. Работает без внешних JavaScript-библиотек; сервер сессий для одиночного режима не нужен.

**Безопасность:** играйте стоя на месте в свободном безопасном помещении/пространстве, не ходите по лестницам, вдоль дорог или среди препятствий, пока смотрите в экран камеры.
