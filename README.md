# ПОЛИГОН / 02.2 — Дуэль через тестовый сервер

**Установка:** заменить `index.html` в корне репозитория GitHub Pages `AR`. Открыть `https://zloirubl777.github.io/AR/?v=22` на двух телефонах после завершения публикации.

## Проверка
1. Первый телефон: «ДУЭЛЬ» → «СОЗДАТЬ КОМНАТУ» → дождаться **«Комната XXXXXX готова»**.
2. Второй телефон: «ДУЭЛЬ» → ввести полученные шесть цифр → «ПОДКЛЮЧИТЬСЯ ПО КОДУ».
3. Дождаться надписи **«Оба телефона соединены» на обоих устройствах**. Нажать «В БОЙ» на каждом, разрешить использование камеры.
4. Чёрный квадрат прикреплён к игроку 2. Игрок 1 стреляет в его сторону. Если алгоритм подтвердил попадание, на втором смартфоне уменьшается здоровье (100 → 80 HP). Поменяться ролями можно с тем же квадратом.

## Что поменялось
Вместо PeerJS + WebRTC используется простой MQTT 3.1.1 поверх защищённого WebSocket. Библиотек и ключей API не требуется. Код комнаты начинается с цифры 1–3, соответствующей одному из тестовых публичных серверов (Eclipse, EMQX, HiveMQ). Все остальные режимы сохранены без изменений.

## Ограничения
- Серверы публичные и доступны без аутентификации: игровые события в принципе можно наблюдать или подделывать. Не отправляйте личные данные. Для выпуска игры потребуется собственный сервер и проверка прав участников.
- Тестовые серверы предоставляются без гарантированной доступности. Игра зависит от интернета на обоих телефонах, но видео с камеры по сети не передаётся.
- Одновременная двусторонняя стрельба требует по одному простому чёрному квадрату на каждом участнике. Для первого теста достаточно одного квадрата и смены ролей.
- Программная проверка соединения и передачи HP проведена с имитацией брокера. Реальная мобильная сеть/серверы не проверены.
