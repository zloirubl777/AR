# ПОЛИГОН 02.0 — сетевая дуэль (2 телефона)

## Установка

Загрузите `index.html` в корень репозитория GitHub Pages, заменив прежний файл. Дождитесь публикации (адрес вида `https://...github.io/AR/?v=20`).

## Первый тест на двух устройствах

1. Откройте одну и ту же ссылку на обоих смартфонах (Safari или Chrome).
2. На первом нажмите «ДУЭЛЬ · ДВА СМАРТФОНА» → «СОЗДАТЬ КОМНАТУ».
3. Передайте второй стороне шестизначный код с экрана. Оставьте первый телефон в открытой комнате.
4. На втором откройте «ДУЭЛЬ», введите код и нажмите «ПОДКЛЮЧИТЬСЯ ПО КОДУ».
5. Убедитесь, что **на обоих** телефонах появился текст «Оба телефона соединены».
6. На каждом телефоне нажмите «В БОЙ · ВКЛЮЧИТЬ КАМЕРУ» и разрешите доступ к камере.
7. Разместите **имеющийся один чёрный квадрат** на светлом фоне на груди второго участника; первый наводит прицел на него и стреляет.
8. На втором экране проверьте уменьшение здоровья (100 → 80 → 60 → ...). Для проверки обратного направления поменяйтесь ролями/передайте квадрат первому игроку.
9. Хозяин комнаты может нажать «↺ НОВЫЙ РАУНД» во время игры, чтобы обнулить здоровье и боезапас.

Важно: один квадрат обеспечивает в конкретный момент захват только того игрока, на котором он закреплён. Для одновременной двусторонней стрельбы обоим участникам понадобится по одному такому же чёрному квадрату (это может быть просто нарисованный/вырезанный квадрат, а не распечатанный кодовый маркер).

## Параметры

- HP: 100 на участника
- Попадание по подтверждённой зоне: 20 HP
- Магазин: 20 патронов, запас: 80
- Перезарядка: 1,55 секунды
- Интервал выстрелов: 310 мс
- Виртуальная зона корпуса относительно простого чёрного квадрата
- При потере подтверждения захвата выстрел не наносит урона

## Сетевые ограничения

WebRTC DataChannel обменивается событиями попадания и состоянием игроков. Видео **не передаётся**. Бесплатный PeerJS Cloud используется только для сигналинга (https://peerjs.com/client/faq). В разных мобильных сетях WebRTC P2P может не установиться без TURN-сервера. Для проверки попробуйте оба телефона в одной Wi-Fi сети. При ошибке соединения следите за статусом в меню дуэли. Эта экспериментальная версия не имеет авторитетного игрового сервера и не защищает от нечестного клиента.

На GitHub Pages код загружается по HTTPS. Для WebRTC требуется интернет; библиотека PeerJS 1.5.5 загружается с CDN jsDelivr.

## Тестирование

Проверены синтаксис JavaScript и сценарий обмена сообщениями на подменённом сетевом клиенте (приём попадания и сброс раунда). Реальное WebRTC-соединение между двумя физическими смартфонами и дальность/устойчивость захвата при беге требуют полевых испытаний.

Используйте только в безопасной свободной зоне, не бегайте глядя в экран, не играйте рядом с дорогами, лестницами, транспортом, опасными предметами.
