# ПОЛИГОН 02.4 — исправление MediaPipe и HUD

## Установка
1. Замените файл `index.html` в корне GitHub-репозитория `AR`.
2. В обоих браузерах откройте `https://zloirubl777.github.io/AR/?v=24` после публикации.
3. Откройте «Дуэль» → «Человек · Без маркера» и нажмите «ПРОВЕРИТЬ / ПОВТОРИТЬ ЗАГРУЗКУ ИИ» до создания комнаты.
4. Дождитесь сообщения об успешной загрузке модели; затем создайте комнату и подключите второй телефон.
5. Если модель не загружается, раскройте подробное сообщение под кнопкой или откройте в бою «Настройки» → «ПОВТОРИТЬ ЗАГРУЗКУ ИИ».

## Изменено в 02.4
- Несколько источников JavaScript-библиотеки MediaPipe: UNPKG, jsDelivr, esm.sh и альтернативный jsDelivr.
- MediaPipe зафиксирован на версии 0.10.22; к каждому источнику соответствует его путь WASM.
- Этап загрузки и диагностика сетевых ошибок; возможен повторный запуск без перезагрузки страницы.
- Короткие предупреждения в игровом HUD вместо полного URL ошибки.
- Сетевые уведомления, индикатор захвата и строка диагностики расположены вертикально, без пересечения.
- В режиме распознавания человека убрана неуместная надпись «виртуальный корпус» от режима маркера.
- Сохранён MQTT-протокол дуэли версии 02.2/02.3, а также режимы квадрата и зомби.

**Важно:** JavaScript и WASM MediaPipe загружаются через интернет, модель — с storage.googleapis.com. Если все указанные сети недоступны на телефоне, браузерная версия не сможет включить распознавание человека. В этом случае временно выберите режим «Чёрный квадрат». Сам факт успешной проверки на эмуляторе не подтверждает доступность ресурсов на конкретном телефоне.
