# ПОЛИГОН 01.3 · Живая цель

Браузерный прототип дополненной реальности. Для испытаний нужен **только один имеющийся чёрный квадрат на светлом фоне** — ничего печатать не нужно. Прототип работает без серверов и внешних библиотек; стрельба является локальной демонстрацией, а не сетевым боем.

## Запуск на телефоне

1. В репозитории `AR` на GitHub замени файл `index.html` новым из этого архива (в корне репозитория), сделай Commit.
2. Дождись публикации GitHub Pages и открой `https://zloirubl777.github.io/AR/?v=13`.
3. Убедись, что написано **ПОЛИГОН / 01.3**; нажми «Запустить камеру» и разреши доступ.
4. Прикрепи чёрный квадрат на ровной светлой поверхности к центру груди добровольного участника. Квадрат должен быть плоским, полностью видимым, хорошо освещённым.
5. В «Настройках» укажи **фактическую ширину чёрной части** квадрата в сантиметрах. По умолчанию 12 см — это только начальное предположение.
6. В «Настройках» включи «Зона поражения корпуса», чтобы стрелять в виртуальный прямоугольник вокруг маркера, либо отключи для попадания строго по квадрату.
7. Проверь захват при ходьбе и поворотах с дистанций 1, 2, 3, 4 м. Записывай FPS и то, когда захват пропадает.

## Что изменилось после 01.2

- Один простой чёрный квадрат: нет загрузки js-aruco2, кодовых маркеров или дополнительных листов для печати.
- Быстрый поиск вокруг последней цели с возвратом к общему поиску при её потере.
- Сглаженная рамка; кратковременная потеря отображается жёлтым пунктиром в течение 0,9 с (можно отключить в настройках).
- Выстрел разрешён только по **свежему** обнаружению (до 0,32 с); по предположительно находящейся там цели попадания не засчитываются.
- Переключатель «Квадрат / Виртуальный корпус». Размер виртуальной зоны регулируется; изначально 3 ширины × 4,2 высоты маркера, со смещением вниз относительно его центра.
- Калибровка приблизительной дистанции по замеренной дистанции до квадрата. Настройки сохраняются в браузере.
- Демо для проверки интерфейса без камеры.

## Важно

- **Виртуальная зона** — лишь прямоугольник, рассчитываемый от расположения квадратной метки. Она не распознаёт человека, руки, ноги, стены или физические препятствия. Выстрел может засчитаться в пустое пространство этой зоны. Использовать только как лабораторный этап.
- **Расстояние приблизительное**. Без настройки реального размера и калибровки число в метрах не следует воспринимать как измерение. При наклонённой метке точность ухудшается.
- Один чёрный квадрат **не определяет личность игрока** и не позволяет безопасно различить нескольких противников одновременно.
- Частота сканирования зависит от модели телефона, освещения, размера метки и состояния браузера. Повышение FPS на синтетическом видео не гарантирует такого же результата на реальном телефоне.
- Использовать на безопасной площадке, не бегать, глядя только на экран, не направлять камеру на транспорт или посторонних.

В архиве всего два файла: `index.html` и `README.md`.
