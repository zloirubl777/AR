ПОЛИГОН 02.3 — ЭКСПЕРИМЕНТАЛЬНАЯ ДУЭЛЬ БЕЗ МАРКЕРА

1. Загрузить index.html вместо старого index.html в корень GitHub Pages репозитория AR.
2. На обоих телефонах открыть страницу с параметром ?v=23.
3. Дуэль → выбрать «Человек · Без маркера» либо «Чёрный квадрат» на каждом телефоне.
4. Создать комнату, подключиться по шестизначному коду, нажать «В бой».
5. При первом запуске «Без маркера» нужен интернет: браузер загружает MediaPipe Tasks Vision и lite-модель Pose Landmarker. Пока грузится модель, вверху экрана появится уведомление; если загрузка не удалась, появляется сообщение MODEL с причиной. Тогда можно выйти и временно выбрать режим квадрата.
6. Навести прицел на человека и выстрелить: голова 40 HP, корпус 20 HP, руки и ноги 10 HP. При двух и более распознанных людях попадание блокируется.
7. В настройках можно включать/выключать отображение зон. Дистанция в режиме без маркера пока НЕ определяется.

ВАЖНО: алгоритм Pose Landmarker не идентифицирует игрока и не измеряет преграды. При посторонних людях, частичном перекрытии, плохом освещении, резких движениях распознавание может быть неверным. Урон рассчитывается на телефоне стреляющего — защита от читов отсутствует. Обработка кадров на устройстве; сервер MQTT передаёт игровые события. Прототип не предназначен для использования возле дорог и препятствий.

Состав: index.html — автономный интерфейс, сетевой транспорт MQTT; распознавание без маркера использует внешние файлы MediaPipe CDN и модель Google (при первом запуске нужна сеть).

Проверено: JavaScript node --check и целостность архива. Реальные два телефона и видеокамера в данном окружении не тестировались.
