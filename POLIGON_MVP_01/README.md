# ПОЛИГОН · MVP 01 — испытание камеры и маркеров

## Состав

- `index.html` — браузерный прототип на JavaScript. Распознаёт до 4 меток, показывает их ID и оценку расстояния, демонстрирует попадания **в область метки**, а не в тело игрока. Работает на стороне клиента.
- `markers.html` — четыре страницы формата A4 с метками игрока #1–#4. Откройте файл и напечатайте с масштабом **100%**.
- `marker_1.svg` … `marker_4.svg` — эти же метки отдельными векторными файлами. При распечатке чёрный квадрат должен быть ровно **12 × 12 см** (белое поле вокруг сохраняется).

## Как запустить на смартфоне

1. Создайте отдельный публичный репозиторий GitHub или используйте существующий, загрузите `index.html` и `markers.html` **в корень**. Если хотите использовать отдельные метки, добавьте `marker_*.svg`.
2. В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**, сохраните настройку.
3. В Safari или Chrome откройте HTTPS-ссылку `https://<логин>.github.io/<репозиторий>/` (или `index.html`), нажмите «Запустить камеру» и разрешите её использование.
4. Напечатайте метку из `markers.html` в масштабе 100%. Для проверки закрепите её на стене или одежде другого человека (хорошее освещение, без бликов). Начните с 1–2 м.
5. Наведите камеру, проверьте, что появились рамка, ID и приблизительная дистанция. Совместите крест прицела с меткой и нажмите «Огонь»: счётчик попаданий должен увеличиться. Пока это **локальный тест**, не сетевой бой.
6. Чтобы уточнить расстояние, откройте настройки, укажите действительный размер чёрного квадрата, измерьте расстояние от камеры до **плоскости метки**, наведите камеру на метку фронтально и нажмите «Калибровать».

## Важное

- Используйте **HTTPS**: камера браузера требует защищённого контекста. Простой запуск файла из памяти телефона может не дать доступ к камере.
- Во время первой загрузки нужен Интернет: `index.html` скачивает два JavaScript-файла библиотеки **js-aruco2 2.0.0** из jsDelivr (если недоступен — с unpkg). Метки доступны без сети.
- Маркер — белое поле вокруг чёрного 7×7 квадрата и 5×5 код внутри. Не прикрывайте код пальцами; печатайте чётко и матово.
- Расстояние рассчитано по перспективному размеру метки и оценке фокусного расстояния камеры. Без калибровки ошибка может быть существенной; при сильных углах, цифровом зуме и бликах она сохраняется и после калибровки. Не использовать для реальных измерений или безопасности.
- Смена камеры/объектива требует повторной калибровки. При плохом освещении и на расстоянии свыше нескольких метров маленькая метка может перестать распознаваться.
- Это **не** распознавание всего силуэта человека и не определение урона другому телефону. Эти функции — следующий этап.

## Техническая основа

Стандартная камера: MediaDevices.getUserMedia. Детектор: js-aruco2 (MIT), https://github.com/damianofalcioni/js-aruco2 . Применён компактный словарь из четырёх выбранных ArUco-кодов. Видео не отправляется на сервер; сеть нужна только для первоначальной загрузки библиотеки.
