# ПОЛИГОН / MVP 01.1 — исправление обнаружения целей

## Что изменено

- Система ищет кодовые маркеры ArUco **и** простой чёрный квадрат на светлом фоне.
- Если кодовый маркер найден, отображается номер игрока #1–4.
- Если найден только простой чёрный квадрат, отображается `КВАДРАТ · ТЕСТ`, без ID. Попадание будет засчитано, если прицел внутри рамки.
- Добавлена строка диагностики под сообщением захвата. При выстреле без найденной цели теперь показывается понятное уведомление.
- `markers.html` содержит **новые более контрастные** кодовые маркеры #1–4 и простой квадрат на отдельной странице.
- **Совместимость:** распознавание старых кодовых маркеров из MVP 01 сохранено.

## Установка на GitHub Pages

1. Замените файлы `index.html` и `markers.html` в корне репозитория `/AR`.
2. Откройте `https://zloirubl777.github.io/AR/?v=11` (добавка `?v=11` помогает не получить старый кеш HTML).
3. Разрешите доступ к задней камере.
4. Напечатайте кодовый маркер #1 с новой страницы `markers.html`. Для первого теста можно использовать лист «ПРОСТОЙ КВАДРАТ».
5. Наведите прицел. Статус должен стать `✓ ЗАХВАТ`, снизу должна отображаться оценка расстояния; нажмите «ОГОНЬ».
6. Если нужен расчёт точнее — в настройках задайте фактический размер чёрного квадрата и калибровочную дистанцию, затем нажмите «КАЛИБРОВАТЬ» при обнаруженной цели.

## Важно

- Для работы камеры нужен HTTPS и разрешение браузера. Детектор ArUco впервые загружается с CDN, поэтому нужен интернет.
- Простой чёрный квадрат не содержит ID. Он годится только для проверки стрельбы, и может ошибочно захватывать похожие тёмные объекты. Для нескольких игроков обязательны кодовые маркеры.
- Расстояние ориентировочное, зависит от оптики, света и наклона квадрата.
- Камера/выстрелы пока работают только на одном телефоне. Нет сетевого боя, нет распознавания силуэта игрока.
- Не используйте игру на дороге, возле транспорта и других опасных препятствий.
