# ПОЛИГОН 02.7 — исправление дуэли и скорости захвата

## Установка
Заменить **только** корневой `index.html` репозитория GitHub `AR` на новый файл. Существующий `.github/workflows/publish.yml` оставить без изменений. Дождаться успешной публикации в GitHub Actions. Оба телефона должны открыть `https://zloirubl777.github.io/AR/?v=27` и показывать версию 02.7.

## Изменения
- Код комнаты теперь показывается только после фактического подключения к MQTT-серверу. Во время проб серверов показано «ПОДКЛЮЧЕНИЕ…» — код не меняется после публикации.
- При временной потере MQTT игра пытается восстановить соединение на **том же сервере и с тем же кодом**.
- Кнопка «ОГОНЬ» при отсутствии сети доступна как «ТЕСТ»: есть вибрация/вспышка/надпись, но урон на второй телефон **не передаётся**. Вместо перезарядки появляется кнопка «↻ СВЯЗЬ».
- Для распознавания человека используются уменьшенные кадры, интервал поиска снижен до 92 мс, что может улучшить скорость на медленных телефонах (без гарантии).
- Переключатель старого чёрного квадрата и режим зомби сохранены; модель MediaPipe по-прежнему загружается с GitHub Pages.

## Проверка
1. Телефон 1: «Дуэль» → «Создать комнату». Код не должен появиться до ответа сервера; после появления больше не меняется.
2. Телефон 2: «Дуэль» → «Войти по коду», затем «Подключиться по коду»; убедиться, что **на обоих** экранах статус «Оба телефона соединены».
3. Нажать «В бой» на каждом телефоне. На игровом экране сверху должна быть «СВЯЗЬ УСТАНОВЛЕНА», кнопка — «ОГОНЬ».
4. Если связи нет: кнопка называется «ТЕСТ» и реагирует, но не наносит сетевой урон. Нажать «↻ СВЯЗЬ». Если это не помогает — открыть диагностику MQTT в меню комнаты.
5. Навести камеру на одного человека, дождаться зелёного захвата и выстрелить. При подтверждённом попадании должен уменьшиться HP второго игрока.

Публичный тестовый MQTT-сервер не гарантирует 100% доступности. В дальнейшем следует заменить его собственным сервером игры. Распознавание человека выполняется на устройстве; использование уменьшенного кадра повышает скорость, но может сократить дальность распознавания мелких силуэтов.
